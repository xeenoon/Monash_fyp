# Detailed terrain vegetation

18 original assets, each with three geometric LODs, authored in metres with
Y up and its pivot at ground centre. Each glTF is standalone except for the
shared `textures/` directory. Keep `models/` and `textures/` beside each other.
The assets use the existing renderer's opaque PBR path, indexed meshes and
explicit tangents. No shader changes or alpha-cutout support are required.

## Contents

| Family | Variants |
| --- | --- |
| Trees | Mature pine, windswept pine, mature spruce, spreading oak, tall oak, giant laurel |
| Saplings | Young spruce, oak sapling |
| Grass | Two meadow clumps, short grass, dry tuft with seed heads |
| Undergrowth | Large fern, small fern, woodland shrub, meadow flowers |
| Deadwood | Fallen branched log, broken stump with root flare |

Trunks, roots, limbs, twigs and fern stems are extruded along smooth 3D curves.
Child branches attach to the same curve evaluated by the sweep, and their
roots are buried inside their parent. Trunk silhouettes incorporate the bark
height maps. Foliage has real cut-out geometry: folded/cambered leaves with
undersides, solid tapered needles, curved grass blades and individual fern
leaflets. There are no billboard crowns or polygonal canopy blobs.

`laurel_giant` is an approximately 18-metre broadleaf tree with a dense,
rounded crown: 55,440 broad oval, leathery leaves on 40 main limbs. Low forks
spread laterally beneath a domed centre, with drooping outer sprays and a low
foliage skirt, following the open-grown tree reference instead of an upward fan.
Its leaf blades are larger and thicker than the oaks, with the same detailed bark and
veined PBR foliage maps. It participates in the existing tree scatter category.

The detailed tree LODs are deliberately expensive close-up assets (roughly
0.7–3.6 million triangles for a mature tree). LOD1 and LOD2 are separate files
with the same seed, placement and woody structure, retaining fewer, slightly
larger foliage elements. Use the manifest's distance thresholds as starting
points, select LOD by screen size, cull out-of-view instances and share uploaded
meshes/materials. Do not submit LOD0 for an entire distant forest. The pack
does not yet include a streaming/instancing system or wind deformation.

## Textures and provenance

The two original scanned bark sets are [Bark Brown 02](https://polyhaven.com/a/bark_brown_02)
and [Pine Bark](https://polyhaven.com/a/pine_bark), from Poly Haven under CC0.
Their 4K albedo, OpenGL normal and AO/roughness/metallic maps are kept intact;
2K height maps also drive small geometric ridges. `material_sources.json`
records URLs, source pages, resolutions and MD5 checksums. Authored leaf,
needle, grass and fern maps are 2K with veins, midribs and roughness variation;
they are generated by the pack builder. Models and authored foliage maps are
original project assets, not downloaded tree models.

## Use and scatter

`manifest.json` contains every model path, LOD threshold, bounds, primitive and
triangle counts, random scale range, spacing radius, slope limit, ground sink,
and trunk collision radius. Trees stay vertical; ground cover can follow the
terrain normal. Preserve the world translation in double precision and make
it camera-relative at draw time, like the terrain's existing meshes.

Generate a placement file directly on a terrain tile:

```sh
python3 tools/scatter_vegetation.py \
  --tile trn-golden/tiles/0/0/0.trn --category tree,sapling \
  --count 100 --seed 7 --out out/vegetation-trees.json
```

Use `--category grass,flowers` or `undergrowth` for other layers. An optional
greyscale `--mask` covers the tile from north to south: black excludes roads,
water or buildings, white allows placement, grey reduces density. The sampler
uses the terrain mesh's triangle diagonal, skips no-data, checks slope and
enforces spacing. Each output instance records the asset id, double-precision
world position, yaw, scale, terrain normal and slope-alignment flag.

This produces placement data for integration; it does not automatically plant
the live terrain. It accepts projected Y-up `.trn` tiles, not geocentric tiles.
Choose one non-overlapping tile level for a scatter pass. Cross-tile spacing,
biome/altitude rules and runtime instance streaming belong to the caller.

## Rebuild and inspect

```sh
python3 tools/download_vegetation_materials.py
python3 tools/build_vegetation.py
python3 tests/vegetation_asset_tests.py
python3 tests/vegetation_scatter_tests.py
blender -b --python tools/render_vegetation.py -- grove out/vegetation-grove.png
```

Python generation requires NumPy and Pillow; downloading also uses `curl`.
The finished assets need neither Python nor Blender. The renderer can load an
individual model through `TERRAIN_SCENE=gltf` and `TERRAIN_GLTF_PATH`.
The Blender reviewer also accepts `ground`, `bark`, or any asset id as its view.
`--only pine_mature,oak_spreading --skip-textures` rebuilds selected models.
