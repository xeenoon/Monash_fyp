# Wall torch asset

`walltorch.obj` is Savino's **Wall torch**, downloaded from OpenGameArt on
2026-09-02. The asset is dedicated to the public domain under CC0.

- Source page: https://opengameart.org/content/wall-torch
- Original download: https://opengameart.org/sites/default/files/walltorch.obj
- Author: Savino
- License: CC0 1.0

The source has no textures or flame. `walltorch.gltf` is the deterministic,
triangulated runtime conversion produced by `tools/convert_wall_torch.py`; its
brown iron/wood material is project-authored metadata around the unchanged
mesh geometry.
